# AEDREA Studio — AI-Powered Digital Growth Studio Website

This repository contains the source code for the **AEDREA Studio** agency platform.

## 🎨 Design & Theme Overview

- **Aesthetics**: High-end modern design utilizing rich GSAP animations, Framer Motion, and Tailwind CSS.
- **Theme**: Premium dark mode layout with custom cursor animations, ambient music players, and clean smooth scroll dynamics.
- **Target Audience**: Digital growth systems, automated chatbot tools, WhatsApp integration, and SEO check services for manufacturers and SMEs.

## 🚀 Features

- **Smooth Scroll**: Controlled via Lenis with custom viewport handling.
- **SEO Checker**: Comprehensive visual and metadata audit dashboard.
- **Automation Showcase**: Interactive service walkthrough panels.
- **Floating Support Call**: Dynamic integration with voice-based call assistants.

## 🛠️ Development & Commands

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Lint files:
```bash
npm run lint
```
